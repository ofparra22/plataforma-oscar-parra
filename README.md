# Plataforma Oscar Parra · Consultor de Marketing

Plataforma para que agencias y negocios consulten sus campañas de Meta Ads y soliciten campañas nuevas a Oscar Parra. Primer espacio de trabajo: Jaque Marketing.

- Instrucciones para Claude Code: `CLAUDE.md`
- Plan por etapas: `docs/PLAN.md`
- Diseños de referencia: `diseno/` (guía en `docs/DISENO.md`)

## Requisitos

- Node.js LTS
- Firebase CLI (`npm install -g firebase-tools`)
- Un proyecto de Firebase en plan Blaze (cuenta de Google personal de Oscar)

## Seguridad

Este repositorio debe ser **privado**. Nunca subas el token de Meta, cuentas de servicio ni archivos `.env`.
